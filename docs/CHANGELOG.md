# TangyiCam 版本紀錄

## 0.4.0 — 發布候選

- 一次性六位配對碼、工作階段到期、嘗試次數限制、電腦端撤銷配對與單一手機控制。
- HTTPS 專用控制端點、來源與 Host 驗證、明確的靜態檔案白名單、受限的 WebSocket 訊息大小與頻率。
- 一鍵產生每台電腦專用憑證；離線 QR、iPhone 安裝步驟與憑證指紋核對。
- 修復背景／斷線後仍送移動、搖桿交換未保存、匯入鏡表文字 HTML 注入與停用外掛 timer 未清理。
- 每次輸出使用新目錄，保留場景狀態；部分影格或編碼失敗明確回報；支援 Blender 內建影片編碼。
- 安裝包與可重建原始碼、授權、第三方來源收據、SHA-256 一同交付。
- 限定 Windows x64；Studio 標示為實驗功能。iPhone 真機驗收尚待完成。
