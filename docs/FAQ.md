# Q&A / 常見問題

[互動 Demo](https://tangyistudio.github.io/tangyicam/) · [English overview](../README.md) · [驗證狀態](QA.md)

## Tangyi Cam 要付費嗎？

免費開源，採 GPL-3.0-or-later。攝影機控制不需要 Workshop 帳號、LLM 或雲端額度。首次設定仍需依教學完成本機 HTTPS 憑證。

## 這個 Demo 真的連到我的 Blender 嗎？

沒有。這是瀏覽器裡的原創幾何練習場，展示轉向、移動、焦段與短 Take 回放。它不會掃描電腦、不會安裝外掛，也不會向本機 Blender 傳送控制指令。

## Demo 的錄製可以輸出 MP4 嗎？

此頁只在記憶體保存最多 15 秒的練習並回放，重整後清除。實際外掛可在 Blender 中保存獨立 Take、編輯關鍵影格並輸出 MP4 與首尾 PNG。

## 手機需要安裝 App 嗎？

不需要另外安裝原生手機 App，使用手機瀏覽器。電腦端需要安裝 Tangyi Cam Blender 外掛。iPhone 首次使用需設定並核對本機憑證。

## 目前支援哪些環境？

Windows x64 搭配 Blender 4.5.10 LTS / 5.1.2 已完成安裝、錄製與輸出測試。iPhone Safari 真機驗收仍待完成；Android、macOS、Linux 尚未列為已驗證平台。

## 手機走路就能追蹤鏡頭位置嗎？

不是。實際外掛用手機陀螺儀控制方向、螢幕搖桿控制位置，不是 6DOF 位置追蹤。本頁 Demo 用滑鼠或觸控拖曳示意方向，不讀取手機感測器。

## 一定會比 AI 運鏡順暢嗎？

沒有這個保證。它提供直接操作鏡頭的方式，預覽速度仍取決於場景、電腦、手機與私人 Wi-Fi。這個輕量練習場的速度不能當成 Blender 效能測試。

## 為什麼需要同一個 Wi-Fi 與 HTTPS？

正式外掛透過私人區域網路傳送預覽與控制。手機感測器權限需安全連線，請按教學設定憑證，勿把服務連接埠公開到網際網路。

## 下載包含 SECONDHAND 的電影場景嗎？

不包含。影片展示電影場景與模擬手機操作；下載提供外掛程式、授權及說明。本頁的幾何練習場則隨原始碼公開。

## 可以商業使用或修改嗎？

可以依 GPL-3.0-or-later 使用與修改。若再散布外掛或衍生程式，需遵守 GPL 的授權及相應原始碼義務，並保留第三方聲明。電影場景與示範媒體不因外掛開源而一併授權。

## 無法配對、陀螺儀被拒絕或輸出失敗怎麼辦？

先看排錯表，確認同一私人 Wi-Fi、本機服務、憑證與一次性配對碼。問題回報請附版本與重現步驟，不要公開配對碼、憑證私鑰或私人場景。

## 排錯 / Troubleshooting

| 狀況 | 先檢查 | 下一步 |
|---|---|---|
| 手機打不開頁面 | 同一私人 Wi-Fi、服務已啟動、目前 LAN IP | 訪客 Wi-Fi 或 AP isolation 可能隔離裝置；先換可互通的私人網路 |
| Safari 提示不信任 | 憑證指紋是否與電腦一致、憑證是否過期或換過 IP | 依完整教學重建／更新憑證，不略過指紋比對 |
| 配對碼不接受 | 新的一次性六位碼；有效期與是否已使用 | 在電腦重新產生配對，不公開代碼或 session |
| 陀螺儀無反應 | HTTPS、動作權限、橫向、歸零 | 權限被拒絕可先用搖桿；真機流程依驗收清單確認 |
| 鏡頭不斷移動 | 手機是否仍按著搖桿、背景切換或網路斷線 | 停止服務／控制，重新配對後先歸零；若重現請回報 |
| 預覽卡頓 | 場景複雜度、預覽品質、電腦負載、私人 Wi-Fi | 用簡單場景比較，降低預覽品質；不以網頁 Demo 的 FPS 推估 Blender |
| 找不到輸出 | blend 是否已儲存、輸出資料夾是否可寫入 | 已儲存：blend 旁 tc_export；未儲存：Documents/TangyiCam/Exports |
| MP4 沒聲音 | 錄製的是鏡頭運動與預覽 | 不含手機麥克風現場音訊，請於後製另行配音 |
| Demo 錄製重整後不見 | 此頁僅在記憶體保存最多 15 秒 | 要保存作品請使用 Blender 外掛 |
