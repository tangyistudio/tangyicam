# TangyiCam 0.4.0 — Windows 發布候選版

用 iPhone 控制 Blender 攝影機。相機方向由陀螺儀提供，位置由搖桿或軌道控制；不是手機實際走位的 6DOF 追蹤。影片與控制訊息留在電腦及私人區域網路，不需 Workshop 帳號或雲端額度。

## 支援範圍

- Windows x64；Blender 4.5 LTS、5.1。驗收目標為 4.5.10、5.1.2。
- iPhone Safari 為第一批真機驗收目標；真機紀錄完成前維持 release candidate。Android、macOS、Linux 尚未列為已驗證平台。
- 手機與電腦在同一個私人網路。公用／訪客 Wi-Fi 可能無法互通。

## 第一次使用

1. 到 Blender 偏好設定 → 取得擴充套件 → 右上選單 → 從磁碟安裝，選擇 `tangyicam-0.4.0-windows-x64.zip`。不要解壓安裝 ZIP。
2. 啟用 TangyiCam。在 3D 視窗按 N，切換 TangyiCam。
3. 按「首次設定／更新憑證」。不需 Python、命令列或另外安裝 mkcert；不會自動修改電腦根憑證信任設定。
4. 按「啟動手機攝影機」→「顯示 QR」。Windows 防火牆若詢問，只允許私人網路。
5. iPhone 使用 Safari 掃第一個 QR，依說明下載憑證、安裝描述檔，再到「設定 → 一般 → 關於 → 憑證信任設定」啟用完整信任。先比對電腦與手機顯示的憑證 SHA-256。
6. 掃第二個 QR，輸入電腦上的六位配對碼，按「啟用陀螺儀」並允許。關閉直向鎖定、橫放手機，按歸零。

## 每天拍攝

開啟自己的 Blender 場景 → 啟動攝影機 → 配對 → 選鏡或自由錄製 → REC → 停止。每次 Take 使用獨立相機，原場景請另存備份。

輸出 MP4、first.png、last.png：選擇錄好的 TC_ 相機，按「輸出 mp4」。若有儲存 blend，結果在旁邊 tc_export；未儲存的場景輸出至使用者 Documents/TangyiCam/Exports。每次輸出建立新目錄，不覆寫前次成果。沒有外部 ffmpeg 時，使用 Blender 內建編碼。影片為取景／預演輸出，不含現場錄音。

手機切到背景或失去連線會停止控制與錄製。回到畫面會嘗試重連，請先確認錄製狀態，必要時歸零。一次只允許一支手機控制；換手機請在電腦按「重設配對／中斷手機」。

## 常見問題

- IP 變更或憑證到期：先停止服務，按「首次設定／更新憑證」，再啟動。沿用同一部電腦的 CA 時，手機不需重装。
- 連線失敗：確認同一私人 Wi-Fi、Windows 防火牆、路由器未啟用裝置隔離。不要開路由器對外轉發。
- 配對碼錯誤：碼限用一次、有效 10 分鐘。查看電腦最新碼；連續錯誤需等一分鐘。
- 沒有預覽：保留至少一個 Blender 3D 視窗；先用 SOLID 模式，必要時降低預覽寬度。
- 卡頓：降低預覽解析度/FPS；複雜材質与場景會影響速度，不承諾固定 FPS。
- 陀螺儀不動：使用 Safari HTTPS，檢查憑證完整信任與動作權限；仍可選「只用搖桿」。
- 輸出失敗：不會回報成片成功。新輸出資料夾保留 error.txt 與已完成影格供診斷。

## 更新與移除

停止攝影機、儲存場景，再安裝新版 ZIP並重啟 Blender。更新不需覆蓋影片、鏡表或憑證。舊版 ZIP 與 SHA256SUMS 可保留作回復。

移除：在 Blender 移除擴充；iPhone 的一般 → VPN 與裝置管理，移除本機 mkcert 描述檔。本機設定在 %LOCALAPPDATA%/TangyiCam，Studio 佇列在 ~/.tangyicam/bridge，匯出影片獨立保存。若確定不再使用，手動移除設定與憑證；不要把 private-ca 或私鑰交給別人。

## Studio（實驗功能）

保留建模、素材匯入、相機路徑、動作重定向與接觸工具。它們是 Blender 編輯工具，不是雲端文字生影片服務，也不保證自動產生可交付的人物打鬥或物理模擬。第一次使用請操作自己的場景副本。
