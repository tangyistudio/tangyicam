Bring the experience into Blender.

01 / INSTALL

Install the add-on ZIP

In Blender Preferences, choose Install from Disk and enable TangyiCam. Keep the ZIP intact; do not extract it first.

02 / CONNECT

Use the same private Wi-Fi

Follow the illustrated guide to set up local HTTPS and verify the certificate fingerprint. Then pair in Safari on your phone and allow sensor access.

03 / RECORD

Record and export

Turn the phone and move with the joystick to record a separate take. Edit it in Blender, then export MP4 and first/last-frame PNGs.

Q&A | Answers before you get started.

Does Tangyi Cam cost anything?

It is free and open source under GPL-3.0-or-later. Camera control needs no Workshop account, LLM or cloud credits. Initial setup still requires a local HTTPS certificate following the guide.

Does this demo connect to my Blender?

No. This original browser scene demonstrates looking, moving, focal length and short take playback. It does not scan your computer, install an add-on or send control commands to Blender.

Can I export this demo recording as MP4?

This page keeps up to 15 seconds of practice in memory for replay. Reloading clears it. The actual add-on saves separate takes in Blender, lets you edit keyframes, and exports MP4 plus first/last-frame PNGs.

Do I need to install a phone app?

No native phone app is required; use a browser on your phone. The computer needs the Tangyi Cam Blender add-on. On iPhone, initial setup includes installing and verifying the local certificate.

Which environments have been tested?

Installation, recording and export have been tested on Windows x64 with Blender 4.5.10 LTS and 5.1.2. Physical iPhone Safari validation is still pending. Android, macOS and Linux are not yet verified platforms.

Does walking with the phone track its position?

No. The actual add-on uses the phone gyroscope for orientation and an on-screen joystick for position; it is not 6DOF positional tracking. This demo uses mouse or touch dragging and does not access phone sensors.

Is it guaranteed to be smoother than AI camera moves?

No. It gives you direct camera control, but preview speed still depends on the scene, computer, phone and private Wi-Fi. This lightweight practice scene is not a Blender performance benchmark.

Why do I need the same Wi-Fi and HTTPS?

The add-on sends previews and controls over your private local network. Phone sensor permissions require a secure connection. Follow the certificate guide and do not expose the service port to the public internet.

Are SECONDHAND film scenes included?

No. The video shows film scenes and simulated phone control. The download contains the add-on, license and documentation. The geometric practice scene on this page is included in the source repository.

Can I use it commercially or modify it?

Yes, under GPL-3.0-or-later. Redistributing the add-on or derivatives requires compliance with GPL licensing and corresponding source obligations, while retaining third-party notices. Film scenes and demonstration media are not licensed with the code.

What if pairing, sensors or export fail?

Start with the troubleshooting guide. Check the private Wi-Fi, local service, certificate and one-time pairing code. Reports should include versions and steps to reproduce, never pairing codes, private keys or private scenes.
