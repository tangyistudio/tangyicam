体験の次は、自分の Blender で。

01 / インストール

アドオン ZIP をインストール

Blender のプリファレンスで「ディスクからインストール」を選び、TangyiCam を有効にします。ZIP は事前に展開しないでください。

02 / 接続

同じプライベート Wi-Fi に接続

図解ガイドに従ってローカル HTTPS を設定し、証明書のフィンガープリントを確認します。スマホの Safari でペアリングし、センサーへのアクセスを許可してください。

03 / 記録

記録して書き出す

スマホで向きを変え、スティックで移動しながら独立したテイクを記録。Blender で編集し、MP4 と最初・最後のフレームの PNG を書き出します。

Q&A｜使う前に知っておきたいこと。

Tangyi Cam は有料ですか？

GPL-3.0-or-later の無料オープンソースです。カメラ操作に Workshop アカウント、LLM、クラウドクレジットは不要です。初回はガイドに従い、ローカル HTTPS 証明書を設定する必要があります。

このデモは自分の Blender に接続しますか？

いいえ。ブラウザ内のオリジナルシーンで、向き・移動・焦点距離・短いテイクの再生を体験するものです。PC のスキャン、アドオンのインストール、Blender への操作コマンド送信は行いません。

デモの記録を MP4 に書き出せますか？

このページでは最長 15 秒の練習をメモリ内に保持して再生します。再読み込みすると消去されます。実際のアドオンでは Blender に独立したテイクを保存し、キーフレームの編集、MP4 と最初・最後のフレームの PNG の書き出しができます。

スマホ用アプリのインストールは必要ですか？

スマホ用のネイティブアプリは不要で、ブラウザを使います。PC には Tangyi Cam Blender アドオンが必要です。iPhone の初回設定ではローカル証明書を設定し、内容を確認してください。

どの環境が検証済みですか？

Windows x64 と Blender 4.5.10 LTS／5.1.2 で導入・記録・書き出しを検証済みです。iPhone Safari の実機検証は未完了です。Android、macOS、Linux は検証済みプラットフォームに含まれていません。

スマホを持って歩くと位置も追跡されますか？

いいえ。実際のアドオンはスマホのジャイロで向きを、画面のスティックで位置を操作します。6DOF の位置追跡ではありません。このデモはマウスやタッチのドラッグで向きを変え、スマホのセンサーは使用しません。

AI によるカメラ操作より必ず滑らかですか？

保証はありません。カメラを直接操作する方法を提供しますが、プレビュー速度はシーン、PC、スマホ、プライベート Wi-Fi に左右されます。この軽量な練習シーンは Blender の性能テストではありません。

同じ Wi-Fi と HTTPS が必要なのはなぜですか？

アドオンはプライベートなローカルネットワークでプレビューと操作情報を送受信します。スマホのセンサー権限には安全な接続が必要です。ガイドに従って証明書を設定し、サービスポートをインターネットに公開しないでください。

SECONDHAND の映画シーンも含まれますか？

含まれません。動画は映画シーンとスマホ操作のシミュレーションを紹介しています。ダウンロードに含まれるのはアドオン、ライセンス、説明書です。このページの幾何形状の練習シーンはソースコードとともに公開しています。

商用利用や改変はできますか？

GPL-3.0-or-later に従って利用・改変できます。アドオンや派生プログラムを再配布する場合は、GPL のライセンスおよび対応するソースコードの提供義務に従い、第三者の通知を保持してください。映画シーンと紹介メディアはコードと同じライセンスでは提供されません。

ペアリング・センサー・書き出しに失敗したら？

まずトラブル対処ガイドを確認し、同じプライベート Wi-Fi、ローカルサービス、証明書、ワンタイムペアリングコードを点検してください。報告にはバージョンと再現手順を添え、ペアリングコード、秘密鍵、非公開シーンは載せないでください。
